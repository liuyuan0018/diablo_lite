## 前提修正

移动端联机**技术上完全可行**。荒野乱斗(Supercell)和暗黑不朽(Blizzard)已经证明了这点。Habby不做联机不是技术问题，是玩法设计问题。

## 核心张力：Brawl Stars 式联机 vs Diablo 式联机

两者的联机本质完全不同：

| | Brawl Stars | Diablo-like Loot ARPG |
|---|---|---|
| **单局时长** | 3分钟，精确可控 | 不确定（"刷几把"可能10分钟也可能1小时） |
| **起始状态** | 所有人同一起跑线 | 玩家装备/等级/流派天差地别 |
| **局内成长** | 无（或轻微） | 持续掉落装备，中途可能停下来比较/更换 |
| **失败代价** | 几乎为零，立即下一局 | 可能丢了稀有掉落，或进度回退 |
| **联机的意义** | 联机**就是**游戏本身 | 单机已经是完整体验，联机是**附加层** |

## 八个玩法设计问题

### 1. 进度不对等 —— 最根本的矛盾

Loot ARPG中两个玩家的战力可能差几倍甚至几十倍。放进同一个副本：
- 按强者调难度 → 弱者一碰就死，纯观光
- 按弱者调难度 → 强者秒杀一切，无聊
- Brawl Stars每局重置，不存在这个问题

暗黑不朽的"解决方案"：用副本匹配等级要求 + 战力碾压让高水平玩家带低水平变成"合法行为"。但这本质上放弃了"联机挑战"的设计——变成"大佬带飞"。

### 2. 掉落分配

- 共享掉落 → 抢装备，毒性
- 独立掉落 → 掉率怎么算？一个人堆MF(寻宝率)，队友受益吗？
- 如果一个玩家AFK 1分钟研究装备词缀，另一个在等——这在PVP游戏中不存在

### 3. 节奏冲突

Loot ARPG的爽点之一是"杀→掉→看→换→变强→杀更快"。这个循环中有个**停顿环节**(看装备/换装备/洗词缀)。单人无压力，联机时一个人在停，另一个在等——体验被破坏。

Brawl Stars没有局内背包，没有装备对比，没有Build调整——打完一局才结算。节奏天然流畅。

### 4. 难度缩放不是线性的

2个玩家 ≠ 2倍难度。两个Build可能：
- 互补(火冰相激触发冻结双倍) → 远超2倍效率
- 互斥(时空术士黑洞吸走元素使暴雪AOE的敌人) → 低于1倍效率

不能简单"乘人数加血量"。

### 5. 会话不对等

"兄弟再来一把" —— 一个人在地铁上还有5站，另一个已经到站了。Brawl Stars承诺3分钟结束，可以精确管理。暗黑副本"大概10分钟吧"——不能。

### 6. Build系统与联机的交互 —— 最有意思的点

我们的Build约束体系(套装×协同×法器)在联机时会产生**涌现行为**：
- 两个元素使组队：轮流触发谐律层数更快，但陨石AOE可能重叠浪费
- 时空术士+元素使：力场聚怪后元素使打AOE → **设计得好就是深度，设计不好就是互斥**

这不是bug，是没有被设计过的交互。**联机可以让Build系统产生单机不会有的体验。**

### 7. "联机为了什么" —— 价值主张问题

- Brawl Stars联机因为**不能单机**。对抗人类是核心乐趣。
- Diablo-like联机因为……？"和朋友一起刷装备"是答案，但这个答案在移动端需要特别设计。PC上可以语音+连刷3小时。手机上能复刻吗？

### 8. 内容消耗加速

这是Habby不做联机的**玩法层面的商业原因**：
- 联机 → 效率更高 → 内容消耗更快
- Habby的模型是"用内容消耗速度控制付费节奏"
- 联机直接加速了内容消耗 = 破坏了变现节奏

## 对我们意味着什么

如果我们要做联机，玩法层面有三个设计支点：

**支点一：联机不是"单机×2"，是需要单独设计的体验。** 两个Build放在一起产生的化学反应(协同或互斥)本身就是新内容。如果我们设计出"两个Build联机时触发套装描述里没有的隐藏效果"——单机玩家会为了体验这个效果而找朋友。

**支点二：不需要解决"全局匹配"。** 限好友邀请制。好友之间的进度差异、节奏差异、会话时长差异天然更容易协调。不需要匹配系统，也就不需要解决"随机队友AFK看装备"的问题。

**支点三：联机的独特价值 = "Build协同"。** PVP联机的价值是"击败真人"。暗黑Like联机的价值可以是"两个Build放在一起会发生单机不可能发生的事"。这是一个设计杠杆——不是复制单机体验，是创造单机无法创造的东西。
