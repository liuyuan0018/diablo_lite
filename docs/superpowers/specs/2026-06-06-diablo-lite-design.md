# Diablo Lite 设计文档

**日期**: 2026-06-06
**技术栈**: HTML5 Canvas + Vanilla JS，单文件，零依赖

---

## 一、概述

一款轻量级 2D 俯视视角刷怪游戏，核心灵感来自《暗黑破坏神》与《吸血鬼幸存者》。主角通过传送技能移动，自动发射火球攻击，三名主动技能配合局外装备养成，逐关挑战。

---

## 二、核心玩法

### 2.1 移动与战斗
- **移动**：无自由移动（无 WASD），仅通过传送技能改变位置
- **自动攻击**：自动锁定范围内最近的敌人，持续发射火球
- **技能**：3 个主动技能，按键 1/2/3 切换当前技能，鼠标点击屏幕释放

### 2.2 技能

| 槽位 | 技能 | 效果 | CD |
|------|------|------|----|
| 1 | 传送 | 瞬间移动到点击位置 | 6s |
| 2 | 黑洞 | 点击位置生成黑洞，2 秒内聚拢范围内怪物，造成微量伤害 | 12s |
| 3 | 暴风雪 | 点击位置生成持续 3 秒的暴风雪区域，AOE 伤害 + 50% 减速 | 15s |

CD 受冷却缩减属性影响（上限 40%）。

### 2.3 局内强化塔
关卡内随机地点刷新临时强化塔：
- **刷新 CD 塔**：触碰后立即重置所有技能 CD
- **电击塔**：触碰后 10 秒内持续对周围怪物造成电击伤害
- 更多可扩展

### 2.4 玩家属性

| 属性 | 说明 | 初始值 |
|------|------|--------|
| HP | 生命值 | 100 |
| ATK | 攻击力 | 10 |
| CDR | 冷却缩减(0-40%) | 0% |
| BulletSpeed | 火球飞行速度 | 200px/s |
| PickupRange | 拾取范围(px) | 40 |
| FireRate | 火球发射频率 | 2/秒 |

## 三、怪物系统

### 3.1 怪物类型（10 种，按关卡解锁）

| 序号 | 名称 | 行为 | 特点 |
|------|------|------|------|
| 1 | 僵尸 | 慢速追击 | 血厚，基础近战 |
| 2 | 骷髅兵 | 中速追击 | 死后复活一次 |
| 3 | 幽灵 | 快速漂移 | 穿墙无视碰撞 |
| 4 | 自爆虫 | 冲撞 | 近身后自爆，AOE 伤害 |
| 5 | 投矛手 | 远程 | 停下投掷弹幕 |
| 6 | 蜘蛛 | 中速追击 | 死后生成 3 只小蜘蛛 |
| 7 | 暗影法师 | 远程+闪现 | 受击后闪现回避 |
| 8 | 吞噬者 | 追击 | 击杀后留下毒池 |
| 9 | 石像鬼 | 环绕飞行 | 外围盘旋后俯冲 |
| 10 | 亡灵骑士 | 冲锋 | 周期性直线冲锋 |

### 3.2 精英词缀
随机附加在普通怪物上：
快速（移速 +40%）、分身、死亡爆炸、吸血、护盾

### 3.3 Boss
- 每关末期出现，多阶段战斗
- 带有预警区域的强力技能
- 击败后掉落稀有以上装备

### 3.4 刷怪逻辑
- **持续刷新**：屏幕边缘出生，密度随时间递增
- **精英波次**：定时触发，3-5 只精英 + 若干小怪
- **Boss**：击杀数达标后出现，Boss 击杀 = 通关

## 四、装备与等级

### 4.1 等级
- 最高 70 级
- 击杀怪物获取经验，每级提升基础攻击和生命
- 关键等级解锁新怪物和新关卡

### 4.2 装备槽位

| 槽位 | 类型 | 主属性 |
|------|------|--------|
| 武器 | 法杖/魔杖 | 攻击力 |
| 头盔 | 头冠/兜帽 | 冷却缩减 |
| 护甲 | 长袍/斗篷 | 最大生命 |
| 戒指 | 戒指 | 火球速度 |
| 项链 | 护符 | 拾取范围 |
| 鞋子 | 靴子 | 传送后短暂加速 |

### 4.3 品质
- 普通(白) → 魔法(蓝) → 稀有(黄) → 传奇(橙)
- 品质越高主属性值越高
- 传奇装备带特殊词缀（如"传送后在原地留下一个黑洞"）

### 4.4 掉落
- 普通怪概率掉落，Boss 必掉稀有以上
- 关卡越高，掉落品质越好

---

## 五、关卡

- 共 10 关，击败 Boss 解锁下一关
- 第 5 关和第 10 关有特殊 Boss
- 难度递增：怪物数量、移速、血量逐关增长
- 关卡间通过准备界面连接，可调整装备

---

## 六、地图

- 开放竞技场，无墙壁障碍
- 纯战斗空间，约 2-3 倍屏幕尺寸（支持所有技能完整施展）
- 暗黑主题色调（深灰/墨绿/暗紫）

---

## 七、视觉风格

- 俯视像素风
- 角色和怪物使用 Canvas 绘制的像素 sprite
- 技能粒子特效、暗黑氛围光影
- 装备外观体现在角色上

---

## 八、UI/HUD

经典暗黑布局：
- **顶部**：HP 条（红色）+ 等级 + 灵魂币数量
- **底部居中**：3 个技能槽，显示技能图标、快捷键、CD 倒计时
- **左上角**：关卡计时器
- **右上角**：击杀计数
- **当前选中技能**：边框高亮
- **准备工作界面**：装备管理 + 属性面板 + 关卡选择

---

## 九、游戏流程

```
主菜单 → 准备界面(装备/属性/选关) → 进入关卡
  → 持续刷怪 + 精英波次 + 局内捡塔
  → Boss 出现 → 击杀 Boss → 通关结算(经验/掉落)
  → 返回准备界面
  → 死亡 → 返回准备界面(保留经验)
```

## 十、技术架构

### 10.1 文件结构
单文件 `index.html`，内嵌 `<style>` + `<script>`。

### 10.2 核心模块

| 模块 | 职责 |
|------|------|
| Game | 游戏主循环(requestAnimationFrame)、状态管理 |
| Player | 玩家状态、自动寻敌、火球发射 |
| Skills | 传送/黑洞/暴风雪逻辑、CD 管理 |
| Projectile | 弹幕池：火球、技能投射物 |
| Monster | 怪物 AI、行为状态机、debuff 管理 |
| Spawner | 刷怪逻辑、精英波次、Boss 触发 |
| Equipment | 装备数据、属性计算 |
| Renderer | Canvas 渲染：世界、实体、粒子、UI |
| Input | 键盘(123切换技能) + 鼠标(点击释放) |
| UI | HUD 绘制、准备界面、菜单 |

### 10.3 游戏循环 (60fps)
1. 输入处理
2. 游戏逻辑更新（实体、AI、碰撞、计时器）
3. 渲染（世界层 → 实体层 → 粒子层 → UI 层）

### 10.4 数据持久化
- `localStorage` 存储角色等级、经验、装备、灵魂币、关卡进度

## 十一、核心数据结构

```javascript
Player: { x, y, hp, maxHp, level, exp, equipment[6], skills[], activeSkillIndex, buffs[] }
Monster: { id, type, x, y, hp, speed, behavior, affixes[], debuffs[] }
Projectile: { x, y, vx, vy, damage, owner, lifetime }
SkillEffect: { x, y, radius, duration, type, damage }
GameState: { stage, enemiesKilled, timer, phase, spawnQueue[] }
```
