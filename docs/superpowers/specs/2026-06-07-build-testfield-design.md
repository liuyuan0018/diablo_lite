# Diablo Lite Build 测试场设计

**日期**: 2026-06-07
**技术栈**: 在现有 ES 模块基础上扩展

---

## 一、概述

为 Diablo Lite 新增独立的 build 测试工具，包含训练木桩、一键配装面板和伤害统计，让玩家快速验证 build 效果而无需进入正式关卡。

**核心约束：测试场内所有装备变更不影响真实角色存档数据。**

---

## 二、测试场地图

### 2.1 入口

准备界面新增「测试场」按钮，点击进入 `screen: 'testfield'`。

### 2.2 地图

- 小型固定地图（1200×1200，约 5×5 屏幕），暗色背景
- 无刷怪、无掉落、无经验、无灵魂币
- 玩家出生在中央偏下

### 2.3 木桩

#### 单目标木桩
- 中央上方放置 1 个无敌木桩（HP 不减，不移动，不攻击）
- 外观：深灰色方形，带准星标记
- 上方实时飘出浮动伤害数字（最后 5 次伤害，0.8s 淡出）

#### 群体木桩
- 单目标木桩右侧放置 3 个聚在一起的木桩（间距 60px）
- 用于测试 AOE build

#### 减伤木桩
- 单目标木桩左侧放置 1 个带减伤标识的木桩
- 预设 30% 减伤（可通过面板调整：无/30%/60%）

#### 木桩数据结构
```javascript
// 木桩使用简化的 monster 数据结构
trainingDummies: [
  { id, x, y, size: 24, color: '#555', label: '单体', damageReduction: 0 },
  { id, x, y, size: 24, color: '#555', label: '减伤(30%)', damageReduction: 0.3 },
  { id, x, y, size: 16, color: '#666', label: '群体A', isGroup: true },
  { id, x, y, size: 16, color: '#666', label: '群体B', isGroup: true },
  { id, x, y, size: 16, color: '#666', label: '群体C', isGroup: true },
]
```

木桩不受击退、黑洞吸附、减速、冻结影响（免疫所有 debuff）。

## 三、伤害统计 HUD

### 3.1 位置

测试场顶部横幅（半透明黑底），显示：

| 指标 | 格式 | 说明 |
|------|------|------|
| DPS | `15,320/s` | 最近 3 秒滚动窗口平均 |
| 总伤害 | `1,245,000` | 累计 |
| 峰值 | `48,500` | 单次最高 |
| 时长 | `02:35` | 自动计时 |
| 重置按钮 | `[重置]` | 清零所有统计（不重置装备） |

### 3.2 浮动伤害数字

- 木桩上方飘出，字体 14px bold，白色→黄色渐变
- y 轴上升 40px 后淡出，持续 0.8s
- 仅显示最近 5 次伤害，旧的自动移除

### 3.3 DPS 计算

```
dpsHistory = [{ time, damage }] // 保留 3 秒窗口
每帧清理过期条目
DPS = sum(damage) / 3
```

## 四、配装面板

### 4.1 位置与交互

测试场右侧面板，宽度 320px，可折叠（点击箭头收起/展开）。

顶部两个 Tab 切换：「预设模板」|「自由搭配」

面板内装备变更**立即生效**，但仅作用于测试场内的沙箱角色副本。

### 4.2 Tab 1：预设模板（5 个）

| 模板名 | 套装 | 槽位配置 | 词缀/协同 | 法器 |
|--------|------|---------|----------|------|
| 火球弹幕 | 无 | 武器+戒指: 穿透火球, 护甲+项链: 火焰风暴, 其余散件 | 熔火之心 | 缓落之羽 |
| 冰法控制 | 无 | 头盔+鞋子: 暴风眼, 护甲+护腕: 急冻光环, 其余散件 | 深寒领域 | 临界碎片 |
| 元素使 | 元素使 4 件 (护腕/腰带/头盔/鞋子) | 武器+戒指: 穿透火球+火焰风暴 | 熔火之心 | 谐律之眼 |
| 时空术士 | 时空术士 4 件 (护腕/腰带/护甲/戒指) | 头盔+项链: 冷却共鸣+虚空行者 | 时空共鸣 | 力场发生器 |
| 混合火冰 | 无 | 武器+戒指: 穿透火球, 头盔+鞋子: 暴风眼, 其余散件 | 火冰相激 | 缓落之羽 |

点击模板 → 清空全部槽位 → 生成对应物品（固定 ilvl 70，词缀满值） → 自动装备。

### 4.3 Tab 2：自由搭配

每个槽位（9 个）一行：

```
[槽位名]  [品质下拉▼]  [效果下拉▼]
```

- **品质下拉**：空 / 白装 / 蓝装 / 黄装 / 传奇 / 套装(get="elementalist") / 套装(get="chronomancer")
- **效果下拉**：根据槽位和品质动态变化
  - 传奇品质：显示该槽位可用的词缀列表（从 LEGENDARY_POWERS 中筛选该槽位 stat 对应的）
  - 套装品质：显示该槽位的套装件名称
  - 其他品质：灰色不可编辑
- 等级固定 70，词缀值固定满值（方便对比测试）

底部「应用」按钮：一键生成并装备所有槽位的配置。

### 4.4 沙箱隔离

测试场进入时：
1. 深拷贝当前角色装备到 `sandboxEquipment`
2. 测试场内所有装备读写走 `sandboxEquipment`
3. 面板修改直接更新 `sandboxEquipment`，立即调用 `calcPlayerStats()` 刷新属性

测试场退出时：
1. 丢弃 `sandboxEquipment`
2. 恢复角色原有装备（未被修改）

## 五、技术实现

### 5.1 新增文件

- `js/testfield.js` — 测试场逻辑（木桩管理、伤害统计、沙箱隔离、面板交互）

### 5.2 修改文件

- `js/game-state.js` — 新增 `game.sandboxEquipment`、`game.damageStats`
- `js/renderer.js` — 新增 `renderTestField()`、配装面板渲染、木桩渲染、浮动伤害数字
- `js/gameplay.js` — `gameLoop` 中新增 `case 'testfield'` 分支
- `js/player.js` — `calcPlayerStats()` 支持从 `sandboxEquipment` 读取（测试场模式）
- `js/projectiles.js` — 木桩碰撞检测（伤害但不击杀）
- `js/input.js` — 测试场面板交互（点击 Tab、下拉、模板按钮）

### 5.3 关键数据流

```
配装面板修改 → sandboxEquipment → calcPlayerStats(sandbox: true) → 刷新属性
攻击木桩 → 伤害计算(含减伤) → 更新 damageStats → 浮动数字显示
退出测试场 → 丢弃 sandboxEquipment → 恢复原 equipment → 返回准备界面
```

### 5.4 木桩碰撞逻辑

在 `updateProjectiles()` 中，增加对 `game.trainingDummies` 的碰撞检测：
- 命中时记录伤害但不减少木桩 HP
- 调用 `recordDamage(amount)` 更新统计
- 生成浮动伤害数字粒子

## 六、非目标（不做）

- 不记录测试场数据到 localStorage
- 不在测试场内提供怪物刷新
- 不做 build 对比（A/B 测试）
- 不做 DPS 曲线图
- 不导出测试数据
- 不影响排行榜（无排行榜系统）
