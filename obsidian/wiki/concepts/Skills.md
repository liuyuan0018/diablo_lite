# 技能系统

Diablo Lite 的技能系统由 3 个主动技能 + 自动攻击火球组成。

## 技能概览

| 快捷键 | 技能 | 基础 CD | 效果 |
|--------|------|---------|------|
| 1 | 传送 | 6s | 瞬间移动到点击位置 |
| 2 | 黑洞 | 12s | 在点击位置生成黑洞(220px)，2.5 秒内聚拢怪物 |
| 3 | 暴风雪 | 15s | 在点击位置生成暴风雪(260px)，3 秒 AOE + 减速 |

按 1/2/3 切换当前技能，**鼠标左键点击屏幕**释放到点击位置。

## 技能交互

- **黑洞**：拉动范围内所有怪物向中心聚拢，也轻微拉动玩家。怪物密集时配合暴风雪打出毁灭性 AOE。
- **暴风雪**：每 0.5 秒造成一次伤害并施加 50% 减速。减速不叠加——始终取最慢值。
- **传送**：唯一移动手段。配合 WASD 微调站位，传送是规避 Boss 大招和快速支援的关键。

## CDR 系统

冷却缩减由头盔装备提供，上限 40%（加上传奇词缀 `globalCDR` 可突破到 60%）。`虚空行者` 词缀直接减秒数，在 CDR 计算之后再扣除。

## 传奇词缀影响

| 词缀 | 影响的技能 | 实现方式 |
|------|-----------|----------|
| 虚空行者 | 传送 CD 减秒 | `max(0.5, baseCD × (1-CDR%) - teleportCD)` |
| 传送余震 | 传送留黑洞 | 在旧位置生成小黑洞(1.5s) |
| 黑洞吞噬 | 黑洞持续 +0.5-2s | 直接加到 duration |
| 暴风眼 | 暴风雪半径 +20-60% | `260 × (1 + blizzardSize/100)` |
| 急冻光环 | 暴风雪减速 +10-30% | `0.5 × (1 + blizzardSlow/100)` 上限 90% |
| 火焰风暴 | 火球及技能伤害 +15-50% | 乘到 atk 上 |

## 关键洞察

技能之间存在 cd 错峰衔接——传送 6s → 躲技能 → 黑洞 12s 聚怪 → 暴风雪 15s 输出。合理衔接可以形成永动循环，配合 CDR 装备和虚空行者构建高频释放的玩法。
