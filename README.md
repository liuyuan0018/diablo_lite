# Diablo Lite

浏览器端暗黑破坏神风格 ARPG 小游戏，纯 JavaScript 实现，零依赖。

## 快速开始

```bash
python server.py
# 浏览器打开 http://localhost:8080
```

## 技术栈

- **零依赖** — 无框架、无打包器，21 个 ES 模块直接运行
- Canvas 2D 渲染，requestAnimationFrame 游戏循环
- Python 无缓存开发服务器

## 游戏系统

| 系统 | 说明 |
|------|------|
| 难度 | 10 关指数曲线（1x → 900x），对标大秘境 |
| 技能 | 传送 / 黑洞 / 暴风雪 + 火球自动攻击 |
| 装备 | 6 槽位，4 品质（普通/魔法/稀有/传说），ilvl 1-70 |
| 传奇词缀 | 8 种（穿透火球、火焰风暴、黑洞吞噬等） |
| Build 体系 | 套装(2) × 传奇协同(4) × 法器(4)，9 槽位 |
| 怪物 | 10 种 + 5 精英词缀 + 多阶段 Boss |
| 角色 | 多角色存档，自动迁移旧存档 |
| 测试场 | 训练木桩 + 一键配装 + DPS 统计 |
