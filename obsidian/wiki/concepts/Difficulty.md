# 难度曲线

难度曲线参照《暗黑破坏神 4》大秘境 1-150 层的指数增长设计。

## 设计哲学

- **前三章**（power 1-5.5x）：70 级内可凭基础属性和技巧通关，不需要 Build
- **第四章起**（power 10x+）：断崖式跳跃，必须依靠装备和 Build
- **第六章**（power 45x）：普通毕业水平
- **第十章**（power 600x）：几乎不可能，对标大秘境 150 层

## 怪物强度计算

```javascript
hp = base.hp × diff.power
atk = base.atk × (1 + diff.power × 0.5)
// Boss 额外: hp ×= diff.bossMult, atk ×= diff.power × 2
```

## 经验曲线

三级经验公式：`expToNext = 100 + level × 40`
- Level 1→2: 140 EXP
- Level 69→70: 2860 EXP
- 总需求约 105K EXP（跨多轮游戏可达）

## 关键洞察

第三章到第四章的跳跃（5.5x → 10x）是设计核心——玩家在前三章反复刷装备、凑 Build，才能在第四章存活。这创造了"刷装备→推进→再刷装备"的核心循环。
