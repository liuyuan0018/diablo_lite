# Firebird's Finery

法师经典火系套装，从 RoS 早期沿用至今，经历多次重做。

## 套装效果（当前版本核心）

- **(2):** 死亡时陨石复活（300 秒 CD）
- **(4):** 对敌人造成火伤时施加燃烧，燃烧敌人对你伤害降低 80%
- **(6):** 对燃烧敌人伤害增加 **5,000%**，燃烧精英时获得 100% 增伤

## 经典 Build

1. **Firebird Mirror Image (S21-S27 meta):**
   - 利用 Mirror Image 复制体扩散 Firebird 燃烧，实现全屏 DoT
   - 曾为 GR150 solo 认可 build

2. **Firebird Twister (S22-S24):**
   - Energy Twister + Mirror Image，控制台版特别强
   - 火焰旋风触发范围伤 + Firebird 燃烧

3. **Firebird Disintegrate (早期):**
   - 引导 Disintegrate 施加火伤燃烧
   - 操作简单但天花板有限

4. **Firebird Meteor (2.6.1 PTR):**
   - 曾短暂流行但被 Tal Rasha Meteor 超越

## 现状

2024-2026 维护模式下被 Tal Rasha 和 Typhon 超越，不再是最优选择，但仍可玩。
