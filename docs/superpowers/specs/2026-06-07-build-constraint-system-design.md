# Diablo Lite Build 约束体系设计

**日期**: 2026-06-07
**基于**: D3 法师 Build 发展史调研 ([obsidian wiki](obsidian/wiki/comparisons/D3-Build-Design-Lessons.md))
**技术栈**: 在现有 `index.html` 单文件基础上扩展

---

## 一、概述

在现有 8 种传奇词缀 + 6 装备槽基础上，新增 **3 个装备槽位**、**2 套玩法约束型套装**、**4 组传奇词缀协同** 和 **法器系统**，将 build 从"无脑堆同一种词缀"升级为"遵守玩法约束换奖励"的深度体系。

核心设计原则（来自 D3 调研）：
- 每个套装提出一个**玩法问题**，增伤是遵守约束的奖励，不是无条件放大
- 正反馈循环必须有**耗散机制**（硬上限或收益递减）
- 离散阈值 > 连续梯度，配装从"越多越好"变为"刚好过线"
- 防御与输出耦合到同一目标，而非各自独立

## 二、装备槽位扩展

### 2.1 槽位变更

从 6 槽位扩展到 9 槽位：

| 类型 | 槽位 | 主属性 | 状态 |
|------|------|--------|------|
| 武器 | 法杖/魔杖 | 攻击力 | 已有 |
| 头盔 | 头冠/兜帽 | 冷却缩减 | 已有 |
| 护甲 | 长袍/斗篷 | 最大生命 | 已有 |
| 戒指 | 戒指 | 火球速度 | 已有 |
| 项链 | 护符 | 拾取范围 | 已有 |
| 鞋子 | 靴子 | 传送后加速 | 已有 |
| **护腕** | 护腕 | 攻击力 | **新增** |
| **腰带** | 腰带 | 最大生命 | **新增** |
| **法器** | 法器 | 套装增强 | **新增** |

### 2.2 套装占用规则

- 套装覆盖 **4 个部位**：护腕 + 腰带 + 任选 2 个旧槽
- 剩余 **5 个槽位** 留给散件传奇
- 法器不占套装计数
- 玩家可以选择不穿套装，走纯散件传奇协同路线（对标 LoD）

## 三、套装系统

### 3.1 套装机制

- 品质：**套装（绿色）**，与传奇（橙色）同级但独立
- 每套 **4 件，3 层效果**（2/3/4 件触发）
- 套装物品本身自带基础属性（同品质主属性），套装效果是额外的
- 同一部位可以同时存在套装件和传奇件，玩家必须取舍

### 3.2 v1 套装

#### 套装一：元素使（Elementalist）

**设计哲学**：元素多样性范式。对标 D3 Tal Rasha's Elements。

**操作约束**：必须交替使用不同元素类型的伤害技能，重复使用归零。

**元素分布**：
- 火球（自动攻击）= 火
- 暴风雪 = 冰
- 黑洞 = 奥术
- 传送 = 无元素（不参与循环）

**2 件 — 元素印记**：
> 释放一个与上一次不同的伤害技能时，获得一层"谐律"（最多 3 层）。每层 +15% 技能伤害。使用重复元素技能重置层数为 0。
- 设计要点：强制交替，惩罚重复。玩家需要"火→冰→奥→火→冰→奥"循环。

**3 件 — 谐律爆发**：
> 达到 3 层时，下一次技能触发"谐律爆发"——释放三色陨石（火陨+冰锥+奥术球）轰炸目标区域，总伤害 = ATK × 3 × 层数。触发后层数归零。
- 设计要点：遵守约束的视觉+伤害奖励。不额外按键，自动触发。

**4 件 — 谐律护体**：
> 每层谐律 +10% 减伤。谐律爆发后留下持续 5 秒的元素光环（半径 200px），光环内敌人受到的元素伤害 +25%。
- 设计要点：防御与层数绑定——操作越好（维持高层数），越硬。满足 D3 原则"防御服务于增伤维持"。

#### 套装二：时空术士（Chronomancer）

**设计哲学**：空间控制范式。对标 D3 Delsere's Magnum Opus + 部分 Archon 节奏。

**操作约束**：黑洞创造"力场"，暴风雪引爆力场换取爆发和 CD 返还。

**2 件 — 力场掌控**：
> 黑洞引力半径 +30%。黑洞结束后在原地留下"奇点力场"（半径 220px，持续 4 秒），力场内敌人减速 60% 且受到伤害 +20%。
- 设计要点：造"我的地盘"。对标 DMO Slow Time 泡泡。

**3 件 — 坍缩奇点**：
> 在奇点力场上释放暴风雪触发"奇点坍缩"——力场在 1 秒后内爆，将所有范围内敌人拉向中心，造成 ATK × 5 伤害。力场被消耗。
- 设计要点：黑洞→暴风雪跨技能联动。玩家在"保留力场控场"和"引爆换爆发"之间决策。

**4 件 — 时空大师**：
> 站在奇点力场内超过 2 秒，传送 CD 重置。触发奇点坍缩后，所有技能 CD 减少 3 秒。
- 设计要点：力场成为节奏引擎。完整循环：造场→站场回传送→炸场→传送走→再造场。

### 3.3 v1 两套对比

| | 元素使 | 时空术士 |
|---|---|---|
| 核心循环 | 技能交替→层数→爆发 | 造场→引爆→回 CD |
| 操作节奏 | 规律交替，惩罚重复 | 位置选择，时机决策 |
| 技能依赖 | 依赖 3 技能轮转 | 依赖黑洞+暴风雪联动 |
| 对标 D3 | Tal Rasha | Delsere + Archon |
| 适合玩家 | 喜欢规律循环 | 喜欢空间和时机判断 |

## 四、传奇协同系统

### 4.1 机制

- 当玩家同时装备两个指定传奇词缀时，自动激活协同效果
- 协同效果独立于套装，纯散件也能触发
- 同一词缀可参与多个协同（如暴风眼同时参与"深寒领域"和"火冰相激"）

### 4.2 词缀标签

| 标签 | 词缀 | stat 键 |
|------|------|---------|
| 火系 | 穿透火球、火焰风暴 | pierce, fireballDmg |
| 冰系 | 暴风眼、急冻光环 | blizzardSize, blizzardSlow |
| 奥术系 | 黑洞吞噬、传送余震 | blackholeDur, blackholeSize |
| 通用 | 冷却共鸣、虚空行者 | globalCDR, teleportCD |

### 4.3 v1 四组协同

**熔火之心（穿透火球 + 火焰风暴）— 同类协同**
> 火球每穿透一个敌人，伤害额外 +10%。若穿透 ≥3 个敌人，最后一个敌人被点燃（3 秒内每秒 ATK×0.5 持续伤害）。
- 设计要点：低穿透线性收益，高穿透质变。鼓励穿透堆叠。

**深寒领域（暴风眼 + 急冻光环）— 同类协同**
> 暴风雪半径内，减速超过 70% 的敌人被冻结 1.5 秒（无法移动和攻击）。每个敌人每 4 秒最多冻结一次。
- 设计要点：阈值质变——堆到 70%+ 减速才触发，激励数值投入。对标 D3 Hydra 断点的离散阈值设计。

**火冰相激（穿透火球 + 暴风眼）— 跨类协同**
> 火球穿过暴风雪区域时，附着冰火双属性。对冻结目标伤害 ×2。
- 设计要点：强制思考释放顺序——先暴风雪铺场 → 火球穿过获 buff → 找冻结目标收割。

**时空共鸣（冷却共鸣 + 虚空行者）— 通用协同**
> 传送后 2 秒内，释放的下一个非传送技能 CD 减半。
- 设计要点：传送入场→快速连发。与时空术士套装天然搭配，但散件也可用。

### 4.4 未覆盖词缀

v1 协同覆盖 7/8 词缀（黑洞吞噬未参与协同），不参与的词缀仍可单词缀堆叠生效。

## 五、法器系统

### 5.1 机制

- 法器是第 9 个装备槽位，独立品质
- 不占套装计数，每套装 1 个专属法器 + 通用法器池
- v1 共 4 个法器：2 个套装专属 + 2 个通用

### 5.2 套装专属法器

**谐律之眼（元素使专属）：**
> 谐律爆发的三色陨石改为追踪最近的目标（单体特化）。伤害提升 50%，但范围大幅缩小。
- 场景：Boss 战。将元素使的 AOE 爆发转化为单体集火。

**力场发生器（时空术士专属）：**
> 奇点力场持续时间 +3 秒（合计 7 秒）。力场内队友（如果有）也享受伤害加成。力场不再被坍缩消耗。
- 场景：持久控场。牺牲爆发换取"永久地盘"。

### 5.3 通用法器

**缓落之羽：**
> 生命 > 80% 时，技能伤害 +25%、移速 +20%。受伤后加成在 3 秒内递减至 0，满血后重新叠。

**临界碎片：**
> 任一技能 CD < 3 秒时，所有技能伤害 +30%。不满足条件时加成消失。

### 6.2 改动范围

- `calcPlayerStats()` — 加入套装效果和协同效果计算
- `Equipment` 模块 — 新增套装品质、法器槽位、协同检测

- 现有的 8 种传奇词缀机制（`getLegendaryEffects()`）保持不变
- 词缀叠加逻辑不变
- 品质系统（白/蓝/黄/橙）不变，绿色套装作为新品质加入
- 关卡、怪物、技能基础机制不变
